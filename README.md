# 吴宇飞 · 个人主页

一个四屏的个人主页：**关于我** → **我的学习记录** → **一键去除图片背景** → **AI 文字生成图片**。

前两屏是纯静态页面，双击 `index.html` 就能看；**后两屏各需要一个本地小服务才能用**，
因为它们要带着 API Key 去调用外部服务——Key 放在网页里会被盗用：

| 第几屏 | 调用的服务 | 用到的环境变量 |
| --- | --- | --- |
| 第三屏 · 一键去除图片背景 | Replicate 的 `lucataco/remove-bg` | `REPLICATE_API_TOKEN` |
| 第四屏 · AI 文字生成图片 | OpenRouter 的 `openai/gpt-5.4-image-2` | `OPENROUTER_API_KEY` |

两个功能共用**同一个** `server.js`，不用起两个服务。

后两屏的页面**从哪儿打开都行**（本地服务的地址、编辑器的预览面板、甚至双击文件）：
脚本会自己去本机那几个端口把服务找出来，找到就用它；
一个都没找到，会在按钮下面写清楚「该做什么」，而不是丢一句看不懂的报错。

## 二、三步跑起来

### 1. 确认装了 Node.js

终端里执行：

```bash
node -v
```

看到 `v18` 或更高的版本号就行（本项目不需要 `npm install`，零依赖）。
没有的话去 https://nodejs.org 装一个 LTS 版。

### 2. 填上自己的 API Key

两个 Key 都填在同一个 `.env` 文件里。只用一个功能的话，另一个留空也行。

**① `REPLICATE_API_TOKEN`（第三屏 · 去背景）**

1. 打开 https://replicate.com ，用 GitHub 账号登录；
2. 进 https://replicate.com/account/api-tokens ，点 **Create token**；
3. 复制那串 `r8_` 开头的字符；
4. 在本文件夹里把 `.env.example` 复制一份，改名成 `.env`，把它填进去：

```
REPLICATE_API_TOKEN=r8_你复制的真实Key
```

> 注意：`remove-bg` 是付费模型，账户需要绑定付款方式才能跑。
> 费用很便宜——官网标注每次约 **$0.00046**，也就是 **$1 大约能跑 2173 次**。
> 如果没绑卡或余额不足，接口会返回 402，页面上会有对应提示。

**② `OPENROUTER_API_KEY`（第四屏 · 文生图）**

1. 打开 https://openrouter.ai ，注册/登录；
2. 进 https://openrouter.ai/settings/keys ，点 **Create Key**；
3. 复制那串 `sk-or-v1-` 开头的字符，填进 `.env`：

```
OPENROUTER_API_KEY=sk-or-v1-你复制的真实Key
```

> 注意：第四屏**按用量真金白银计费**，且比去背景贵得多。实测这个模型：
>
> | 质量档位 | 耗时 | 单张费用 |
> | --- | --- | --- |
> | 快速（low） | 约 15 秒 | 约 $0.006 |
> | 标准（medium） | 约 35 秒 | 约 $0.05 |
> | 高清（high） | 约 75～120 秒 | 约 $0.13 |
>
> 网页上默认选的是**标准**档，按钮旁边也会实时显示预估耗时。
> 去 https://openrouter.ai/credits 充值，余额在 https://openrouter.ai/settings/credits 看。
>
> 另外你的 Key 可以在创建时设**额度上限**和**过期时间**——建议设一个，
> 万一泄露了损失也可控。

### 3. 启动服务

**方式 A（推荐，最省事）**：双击 `启动.command`。

> 首次双击若被系统拦下，右键 → 打开 → 仍要打开。

**方式 B（终端）**：

```bash
cd ~/Desktop/9.29上课网页
node server.js
```

两种方式都会打印一行网址，用浏览器打开它：

```
  ✅ 服务已启动
  🌐 打开网页：  http://localhost:8787
  🔑 Replicate： 已读取到 REPLICATE_API_TOKEN（第三屏·去背景）
  🔑 OpenRouter：已读取到 OPENROUTER_API_KEY（第四屏·文生图，模型 openai/gpt-5.4-image-2）
  ⏹  停止服务：  按 Control + C
```

启动后直接访问 `http://localhost:8787` 就行。
哪个 Key 没读到，那一行会变成 `⚠️  没读到`，照着上面的第 2 步补上再重启即可。

**页面从哪儿打开都能用**——本地服务地址、编辑器的预览面板、甚至直接双击 `index.html`。
脚本会先问「当前这个地址」上的 `/api/health`，不是本项目的服务就依次问
`127.0.0.1:8787` ~ `8797`（和 `server.js` 的端口自动顺延范围一致），找到谁就用谁。
所以哪怕服务是刚启动的，页面也不用刷新，再点一次按钮就接上了。

> 双击 `index.html`（`file://`）实测也能用：页面会自己去问本机那几个端口。
> 服务没开的时候才会提示「还没连上本地服务」。

停止服务：回到终端窗口按 **Control + C**。

## 三、Key 是怎么藏起来的

这是这一屏最关键的设计，值得单独说清楚：

```
┌──────────────┐   POST 图片    ┌────────────┐  带 Key   ┌─────────────────────┐
│  index.html  │ ─────────────▶ │ server.js  │ ────────▶ │ api.replicate.com   │
│   （浏览器）  │ ◀───────────── │ （本机）    │ ◀──────── │ lucataco/remove-bg  │
└──────────────┘   返回 PNG     └────────────┘  结果地址  └─────────────────────┘
                 Key 不在这一侧              Key 只存在这一侧
```

- **为什么不直接在网页里 `fetch` 这些服务？**
  一是浏览器跨域（CORS）拿不到响应；二是更要命的——网页里的任何代码，
  任何人按 F12 都能看到，Key 一泄露就可能被别人拿去刷钱。
  （对比一下：右上角那个天气卡片调的 Open-Meteo **不需要 Key**，所以它就直接在前端
  `fetch` 了——「要不要走后端」的判断依据就是「这个接口要不要密钥」。）
- **Key 存在哪里？** 只存在服务端的**环境变量**里：`REPLICATE_API_TOKEN` 和 `OPENROUTER_API_KEY`。
  `server.js` 启动时会先读一次 `.env` 文件，把它塞进 `process.env`。
- **优先级**：系统里真实存在的环境变量 > `.env` 文件。
  也就是说你也可以不用 `.env`，改成这样启动：

  ```bash
  export REPLICATE_API_TOKEN=r8_你的Key
  export OPENROUTER_API_KEY=sk-or-v1_你的Key
  node server.js
  ```

- 改完 `.env` 之后**必须重启服务**才会生效（环境变量是启动时读一次的）。
- `.env` 已经写进 `.gitignore`，不会被 git 提交。也**不要**把它发给别人、传网盘或塞进作品集压缩包。
- 服务只监听 `127.0.0.1`，同一个 WiFi 下的其他人打不开，不用担心被蹭。

## 四、在页面上怎么用

### 第三屏 · 一键去除图片背景

1. 把图片**拖进虚线框**，或点一下框选文件（支持 JPG / PNG / WebP，单张不超过 12 MB）；
2. 点 **「去除背景」**——处理期间按钮会**变灰并显示「处理中…」**，防止重复点击；
3. 左边是原图，右边是结果；右边的**灰白棋盘格代表透明区域**；
4. 成功后点 **「下载 PNG」** 保存，文件名形如 `原文件名-去背景.png`；
5. 想换一张点 **「换一张」**。

几个已经处理好的细节：

- **图片太大时先在浏览器里压一压**：超过 1.5 MB 会用 canvas 缩到最长边 1600px
  再上传，传得更快也更稳；文件名旁边会标注实际压缩后的尺寸。
- **失败会在页面上说明原因**：没配 Key、Key 失效、余额不足、超时、连不上服务，
  都有对应的中文提示，不会只留一个转圈。
- **有 3 分钟超时**：不会一直卡在处理中。

### 第四屏 · AI 文字生成图片

这一屏的界面是**谷歌极简风格**：白底、细边线、胶囊形的筛选控件、蓝色主按钮。

1. 输入框里写一句你想要的画面（右下角有字数统计，上限 2000 字）；
   想省事可以点最下面「试试这些」里的示例，会直接填进输入框；
2. 选 **比例**（1:1 / 4:3 / 3:4 / 16:9 / 9:16）、**质量**（快速 / 标准 / 高清）、**张数**（1 / 2 张）；
   按钮右边会实时显示这一档大概要等多久；
3. 点 **「生成图片」**——生成期间按钮会**变灰并显示「生成中…」**，
   中间的圆点是 Google 那四个颜色在跳，下面还有「已等待 N 秒」的计时，不会让你以为卡死了；
4. 出图后每张自成一张卡片，右下角 **「下载」** 保存，文件名取你自己的提示词前几个字；
5. 底部会显示这次用了多久、花了多少钱、用的哪个模型。

细节说明：

- **提示词可以换行**，所以是 **Cmd + Enter**（Windows 上是 Ctrl + Enter）触发生成，不是回车；
- **质量档位决定等待时间和花费**，差得挺多：快速档十几秒、几美分；高清档要一两分钟、约 $0.13；
- **有 6 分钟超时**；服务端自己等 5 分钟，到点会明确告诉你「等到 5 分钟还没出图」；
- 一次最多 2 张（`server.js` 里允许到 4 张，需要的话把 `index.html` 里的「张数」那一组
  按钮加一个 `data-v="4"` 即可）。

## 五、接口说明（想自己接别的东西时看）

服务一共三个接口：

### `GET /api/health`

页面加载时用它自查。返回：

```json
{
  "ok": true,
  "hasToken": true,
  "model": "lucataco/remove-bg",
  "hasOpenRouterToken": true,
  "imageModel": "openai/gpt-5.4-image-2"
}
```

> 前三个字段还有第二个用途：页面靠 `ok` 和 `model` **认脸**，
> 判断对面是不是本项目的服务（别的静态服务器返回的 404 页面在这儿会被挡掉）。
> 所以改这个接口时，「`ok: true` + 有 `model` 字段」这两条得留着。

### `POST /api/remove-bg`

| 项目 | 说明 |
| --- | --- |
| 请求体 | 图片的**原始二进制**（不是表单） |
| `Content-Type` | 例如 `image/jpeg`、`image/png` |
| 成功返回 | `200`，响应体就是 PNG 图片本身 |
| 失败返回 | 对应的状态码 + `{"error": "中文说明"}` |

命令行试一下：

```bash
curl -X POST -H "Content-Type: image/jpeg" \
     --data-binary @IMG_3392.JPG \
     http://127.0.0.1:8787/api/remove-bg --output out.png
```

### `POST /api/generate-image`

| 项目 | 说明 |
| --- | --- |
| 请求体 | JSON，见下 |
| 成功返回 | `200` + JSON，图片是 **base64**（不是网址） |
| 失败返回 | 对应的状态码 + `{"error": "中文说明"}` |

请求体：

```json
{
  "prompt": "一只橘猫坐在窗台上晒太阳，扁平插画风格，白色背景",
  "aspect_ratio": "16:9",
  "quality": "high",
  "n": 1
}
```

| 字段 | 取值 | 默认 |
| --- | --- | --- |
| `prompt` | 必填，1～2000 字 | — |
| `aspect_ratio` | `auto` / `1:1` / `3:2` / `2:3` / `4:3` / `3:4` / `16:9` / `9:16` / `21:9` | `auto` |
| `quality` | `auto` / `low` / `medium` / `high` | `auto` |
| `n` | 1～4（网页上只开放到 2） | `1` |

> 传了范围外的值不会报错，服务端会**过滤掉**、退回默认值——
> 因为这些取值范围是从模型的端点接口里读出来的，传它不认的值会被上游拒掉。

成功返回：

```json
{
  "ok": true,
  "model": "openai/gpt-5.4-image-2",
  "elapsedMs": 36621,
  "costUsd": 0.0529,
  "images": [ { "b64": "iVBORw0KGgo...", "mediaType": "image/png" } ]
}
```

命令行试一下：

```bash
curl -X POST -H "Content-Type: application/json" \
     -d '{"prompt":"一只橘猫坐在窗台上晒太阳","aspect_ratio":"1:1","quality":"low"}' \
     http://127.0.0.1:8787/api/generate-image
```

服务端拿到提示词后会调
`POST https://openrouter.ai/api/v1/images`（OpenRouter 的 Image API），
请求体就是 `{model, prompt, aspect_ratio, quality, n}`，几乎原样转发。
返回的图片是 base64 而不是网址，所以服务端**不做落盘**，直接把 base64 交给网页，
由网页拼成 `data:image/png;base64,…` 显示——省一次写文件，也不留临时文件在服务器上。

> **为什么用 Image API 而不是 Chat Completions？**
> OpenRouter 两条路都支持：`/api/v1/chat/completions` 配 `modalities:["image","text"]`，
> 图片放在 `choices[0].message.images[].image_url.url`；
> 或者用专门的 `/api/v1/images`，图片在 `data[].b64_json`。
> 这里选了后者：参数（比例/质量/张数）是**一等公民**，不用塞进提示词里碰运气，
> 返回结构也更干净。
>
> 想看这个模型到底支持哪些参数，直接打它的端点接口最准
> （网页上的参数面板是 JS 渲染的，抓不到）：
>
> ```bash
> curl https://openrouter.ai/api/v1/images/models/openai/gpt-5.4-image-2/endpoints
> ```

### 跨域（CORS）说明

服务只对「本机页面」放行跨域请求：

| 请求来自 | 是否放行 |
| --- | --- |
| `http://localhost:任意端口` / `http://127.0.0.1:任意端口` | ✅ 放行 |
| `file://` 打开的页面（浏览器发的 `Origin` 是字符串 `null`） | ✅ 放行 |
| 别的网站（`https://随便什么站点`） | ❌ 不点头，浏览器会拦住 |

最后一条是有意为之：不拦的话，别人网页上的一段脚本就能调用你本机的这个服务、
刷掉你的额度。所以外网站点来问，服务不会返回跨域许可头。
（服务本身也只听 `127.0.0.1`，局域网里的其他设备连都连不上。）

另外，带 `Content-Type: image/*`（第三屏）或 `application/json`（第四屏）的 POST
都属于浏览器的「非简单请求」，会先发一个 `OPTIONS` 探路——服务已经处理好了，返回 `204`。

服务端拿到图片后会：转成 data URI → 调
`POST https://api.replicate.com/v1/predictions`（**必须带上版本号**，见下）
（附带 `Prefer: wait=60` 让它跑完直接返回，没跑完就每 1.5 秒轮询一次，
最多等 2 分钟）→ 把结果 PNG 下载下来转给网页。

> **为什么必须带版本号？**
> `lucataco/remove-bg` 是 2023 年发布的社区模型，Replicate 上**没有给它设置默认版本**，
> 所以按模型名调用的那个接口（`/v1/models/{owner}/{name}/predictions`）会直接返回 404。
> 只能改成按版本号调用：`/v1/predictions` + `{"version": "95fcc2a2...", "input": {...}}`。
> 版本号写在 `server.js` 的 `MODEL_VERSION` 里。
>
> 官方文档里把「按模型名调用」写成了推荐做法（确实更方便，换版本不用改代码），
> 但那只对**有默认版本**的模型成立——这是实测才发现的坑。

模型的输入输出（从版本接口的 openapi_schema 里读到的，可以直接核对）：

| | 定义 |
| --- | --- |
| 输入 | `image`，类型 `string`、格式 `uri`，**必填**，说明是「Remove background from this image」 |
| 输出 | `string`、格式 `uri`，也就是一张 PNG 的地址 |
| 状态 | `starting` / `processing` / `succeeded` / `canceled` / `failed` |

也就是说这个模型**只有一个输入参数**，没有「边缘精度」「输出尺寸」这类可调项。

## 六、常见问题

**页面上提示「还没连上本地服务」**
服务没启动，或者已经被关掉了。在项目文件夹里执行 `node server.js`（或双击 `启动.command`），
然后**不用刷新页面**，直接再点一次按钮——脚本会重新去找一遍服务。

**提示「本地服务返回 HTTP 404」**（旧版本的报错，现在不会再出现这种说法了）
这句话的意思是：页面把请求发给了**一个不是本项目服务的服务器**，对方当然不认识
`/api/remove-bg` 这个路径。最常见的原因是页面不是从本地服务打开的——
比如编辑器预览面板、或者别的静态服务器发出来的页面。
早先版本的自查逻辑有个漏洞：只挡了「完全连不上」，没挡「连上了但不是我们要的服务」，
所以 404 被当成了正常返回、悄悄放过去，直到点按钮才炸出来。
现在的做法是**认脸**：`/api/health` 必须回 `{"ok":true,"model":"..."}` 这样的内容，
认不出来就继续找本机那几个端口；都找不到就把「该做什么」写明白。

**提示「和本地服务的连接断了」**
请求发到一半服务被关掉了（终端窗口被关、或者 Control + C 了）。
确认 `node server.js` 还在跑，再点一次即可。

**提示「服务端没有读到 REPLICATE_API_TOKEN」**
`.env` 没建、文件名写错了（要是 `.env` 不是 `.env.example`）、
或者填完没重启服务。改好后 Control + C 停掉再 `node server.js`。

**提示「Replicate 拒绝了这个 Key（401）」**
Key 复制错了或已失效，去 https://replicate.com/account/api-tokens 重新建一个。

**提示 402**
Replicate 账户还没绑定付款方式，或余额不足。

**提示「Replicate 限流了（429）」**
这是**账户级**的限制，不是 Key 的问题。官方给的规则是：

> 账户余额不足 $5 时，创建任务的频率被压到 **每分钟 6 次，且同时只能有 1 个任务在跑**。

所以连着点「去除背景」很容易撞上。服务端已经会自动处理：遇到 429 时读 Replicate
返回的 `retry_after`，等够时间后自己重试（最多 3 次），页面上会一直显示「处理中…」，
不用你手动重来。如果重试完还是被限，页面上才会提示稍等再试。
实在频繁的话，隔十几秒点一次就好。

**为什么第一次跑要 20 多秒，后面快**
模型本身只跑 1 秒左右（官网标注典型 3 秒内）。首次慢通常是撞上了上面那个限流，
在等自动重试；另外第一次调用还有冷启动。正常情况 2～5 秒。

**提示「服务端没有读到 OPENROUTER_API_KEY」**
`.env` 里没写这一行、Key 复制少了字符，或者改完没重启服务。
去 https://openrouter.ai/settings/keys 重新复制一次，重启服务即可。

**提示「OpenRouter 拒绝了这个 Key（401）」**
Key 写错了，或者**已经过期**。OpenRouter 创建 Key 时可以设过期时间，
到期的 Key 会直接 401；去 https://openrouter.ai/settings/keys 看一眼状态，
失效就新建一个（顺手把过期时间设长一点）。

**提示「OpenRouter 账户余额不足（402）」**
去 https://openrouter.ai/credits 充值。注意第四屏比第三屏贵得多：
高清档一张约 $0.13，快速档约 $0.006。

**第四屏为什么这么慢**
因为它是真的在画图，不是查表。实测：快速档约 15 秒、标准档约 35 秒、高清档 75～120 秒。
页面上按钮旁边会写清这一档大概要等多久，生成中还有「已等待 N 秒」在走，
所以不用盯着怀疑卡死了。**急着看效果就先用「快速」档。**

**第四屏超时了**
服务端最多等 5 分钟，前端 6 分钟。超时基本都是选了高清档 + 比例特别大（比如 21:9）。
换个档位或换个比例再试。

**是不是可以同时开好几个生成任务**
不建议。虽然这个 Key 没有请求频率限制，但每个任务都在真的烧钱，
而且同一时间跑多个容易双双超时。等上一个出图再发下一个。

**提示图片太大**
单张超过 12 MB 会被挡下。先用预览或画图工具压一下再传。

**端口被占用**
服务会自动往后找一个可用端口（8787 被占就用 8788），
**以终端打印出来的网址为准**。

**iPhone 拍的 HEIC 图片**
部分浏览器解不开这种格式（会自动改为原图直传，可能因体积过大失败）。
在手机或「预览」里导出一份 JPG 再传最稳。

**只想给别人看静态页面、不要这两个工具**
直接双击 `index.html` 就行，前两屏完全正常，后两屏会提示需要本地服务。
或者把 `index.html` 里 `<!-- 第三屏 ·` 和 `<!-- 第四屏 ·` 那两个整段
`<section class="screen">` 删掉，再把末尾对应那两段 `<script>` 一起删掉即可
（注意别删掉中间那段「共用 · 找本地服务」的脚本之外的东西——
第四屏的脚本删掉后，共用脚本没人用也无所谓，留着不影响）。

**天气卡片为什么不用 Key？**
它调的是 Open-Meteo 的免费公开接口（https://open-meteo.com），无需注册，
所以直接在前端 `fetch` 就行——这也正好和后面两屏形成对比：
**不需要密钥的接口可以前端直接调，需要密钥的必须走后端。**

## 八、如果以后要发布到公网

现在这套东西是给本机用的，直接上线是不行的，至少要改三处：

1. `server.js` 得有公网地址（云服务器、Vercel / Cloudflare Workers 之类），
   两个 Key 都放进平台自己的环境变量里，不要打进代码；
2. **一定要加限流**（比如每个 IP 每天几次），否则别人可以拿你的页面免费刷你的额度；
3. 上传体积、并发都要设上限，避免被打爆内存。

在那之前，它就是一个安安静静待在你自己电脑上的小工具。
