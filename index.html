第一次 API 调用

第一次让网页主动向外部服务要数据：用 fetch 调用 Open-Meteo 的免费天气接口， 把返回的 JSON 解析出来，渲染成页面右上角的实时天气卡片。 不用申请 API Key，也第一次明白「数据不在本地，而在别人的服务器上」， 所以必须处理加载中、请求失败和网络超时这些情况。

  • JavaScript
  • fetch
  • Open-Meteo
  • JSON
2026.09.29

一键去除图片背景

第一个需要 API Key 的接口：拖一张图片进来，交给 Replicate 上的 remove-bg 模型， 几秒钟后拿回一张透明背景的 PNG，可以下载。 过程中也第一次明白「Key 不能放在前端」——网页只跟自己写的本地服务说话， Key 藏在服务端的环境变量里；服务还得会处理「正在处理中」「Key 没配」「图片太大」这些情况。

  • Node.js
  • Replicate
  • 环境变量
  • 拖拽上传
2026.09.29

AI 文字生成图片

写一句提示词，让网页把画面「画」出来。用的是 OpenRouter 上的 gpt-5.4-image-2，接口返回的是 base64 而不是图片网址，所以不用落盘。 Key 和去背景那屏一样藏在服务端；不一样的是这屏「按用量真金白银计费」， 快慢和价格差好几倍，页面上就得先把「这一档大概等多久、花多少钱」写清楚， 生成时还要显示已经等了多久，不然很容易被当成卡死。 界面单独试了一次谷歌的极简风格。

  • OpenRouter
  • 文生图
  • base64
  • Material 风格
